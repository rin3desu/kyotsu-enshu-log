# 共テ演習ログ

大学入学共通テストとセンター試験の過去問演習を記録し、次に解く試験と復習する単元を確認するWebアプリです。生徒の演習記録と、講師による生徒別の確認・コメントに対応します。

## 主な機能

- **演習記録** — 年度・試験区分・科目を選び、解答番号や記号ごとの○×と大問別の得点を保存します。
- **演習チェック** — 科目と年度の表で未演習の過去問を確認できます。演習済みの欄には直近の得点を表示します。
- **単元分析** — 単元別の正答率と復習テーマを表示します。地理では地誌を地域別に分類し、資料で照合できた設問は解答番号ごとに集計します。
- **講師画面** — 生徒アカウントを発行し、生徒ごとの演習履歴や大問別の結果を確認してコメントを送れます。
- **スマートフォン対応** — iPhoneのホーム画面追加用アイコンを備え、チェック表は科目列を固定したまま横にスクロールできます。

2016〜2026年度の本試験・追試験を対象とし、数学Ⅰ・A、数学Ⅱ・B／B・C、物理、化学、地理を収録しています。2025年度は旧課程科目も含みます。

## 技術構成

| 用途 | 技術 |
| --- | --- |
| 画面・採点入力・集計 | HTML、CSS、標準JavaScript |
| アクセス制御とデータAPI | Cloudflare Worker |
| アカウント・演習記録・コメント | Cloudflare D1、SQLマイグレーション |
| ビルドと本番配信 | Node.js、OpenAI Sites |

生徒のIDとパスワードによるログイン、講師のChatGPTサインイン、認証済みの生徒単位のデータアクセスを実装しています。問題・正解・解説は、大学入試センターや予備校などの参照リンクから閲覧します。

## 手元で試す

`dist/index.html` をブラウザで開くと、端末内の保存を使って演習の登録やチェック表を試せます。講師画面・生徒ログイン・端末間の共有はホスト環境で動作します。

リポジトリのルートで `node build.mjs` を実行すると、Workerのエントリーポイント `dist/server/index.js` を生成します。D1のバインディング名は `DB` です。スキーマは `drizzle/` にあり、講師認証にはSitesから渡される認証済みの利用者情報と、実行環境のシークレット `TEACHER_EMAIL` を使います。本番の接続設定と利用者データは、このリポジトリには含まれていません。

## 今後の構想

問題冊子・公式正解と答案画像の途中式を照合し、誤答の原因候補と復習手順を講師向けのコメント案として提示する機能を検討しています。現行の復習提案は、登録済みの単元・地域と正誤の集計に基づきます。
